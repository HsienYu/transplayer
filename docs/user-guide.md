# User guide / 安裝與操作手冊（給藝術家與美術館）

這份手冊假設你是第一次安裝,照著順序做即可。需要用到終端機的步驟都會完整列出指令。
遇到不確定的狀況,先停下來、保留畫面訊息,聯絡技術人員,不要強行繞過。

## Platform / 平台（正式版）

**正式安裝平台為 Ubuntu 26.04 LTS、amd64（x86_64）、預設 GNOME 50 桌面、Wayland／Xwayland。**
目前的套件版本是 `1.1.0~rc4`,已在參考展場機(MSI MS-7D17／RTX 4060)完成安裝、重開機與自動播放驗證。
ARM、其他桌面環境、其他 Ubuntu 版本不在支援範圍。舊的 Ubuntu 25.10／r9 現場不用這份流程升級。

尚未完成的項目(不影響一般安裝,但轉為長期展出前建議補齊):長時間連續 soak 測試、
發行前的授權／漏洞／lintian 稽核。這些由技術人員處理。

## 你需要準備的東西 / Requirements

1. **一台專用電腦**,已安裝 Ubuntu **26.04 LTS（amd64）**,一個一般展示用帳號(非 root)。
   建議現代多核心 CPU 加一張獨立顯示卡(參考機為 RTX 4060);見下方「效能」。
2. **兩台直向螢幕**,各 **1080×1920**,左右相鄰、頂端對齊、縮放 **100%**、延伸桌面(不要鏡像),
   合成桌面為 **2160×1920**。可先接好,方向稍後在系統設定裡調。
3. **作品影片檔**(另外向專案取得,不隨程式散布):檔名 `stonesandelephants.webm`,
   規格 **2160×1920、約 780 秒**。見下一節放置位置。
4. **安裝套件檔**:`transplayer_1.1.0~rc4_amd64.deb`,以及它的 **SHA-256** 校驗值(見「安裝」)。
5. **網路**:即時圖片搜尋需要連網。第三方網站可能改版或要求驗證,無法保證永遠不出現 CAPTCHA
   (本版已內建自動處理,見「常見問題」)。
6. **管理員密碼**:只有「安裝套件」這一步需要;之後的設定與播放都用一般帳號,**不要 sudo**。

## 影片檔案放哪裡 / Video file location

- 把 `stonesandelephants.webm` 放在**展示帳號可讀取、而且會一直存在**的本機資料夾。
  參考展場機放在:
  ```
  /home/<展示帳號>/Desktop/transplayer-master/video/stonesandelephants.webm
  ```
  例如帳號是 `museum`,就是 `/home/museum/Desktop/transplayer-master/video/stonesandelephants.webm`。
  放 `~/Videos/` 之類的固定資料夾也可以。
- **不要**放在隨身碟或會被拔除／自動卸載的外接裝置——開機時找不到影片會無法播放。
- 設定工具只會**讀取並記住**這個路徑,不會搬移、轉檔或覆寫你的影片。之後若把影片換位置,
  要回設定工具重新選一次。

## 安裝 / Install（套件這一步需要管理員）

1. 把專案提供的 `transplayer_1.1.0~rc4_amd64.deb` 放到展示帳號的下載資料夾,例如 `~/Downloads/`。
2. **先核對檔案雜湊**,確認拿到的是正確、未被竄改的檔案。開啟「終端機」,執行:
   ```sh
   sha256sum ~/Downloads/transplayer_1.1.0~rc4_amd64.deb
   ```
   輸出的雜湊必須完全等於專案提供的值:
   ```
   b2a8dbc051a6dfc04b55d944b005154c4f24f391485bb2cf5dbc2322f23ab104
   ```
   不一致就**不要安裝**,重新向專案索取檔案。
3. 安裝套件(會要求輸入管理員密碼):
   ```sh
   sudo apt install ~/Downloads/transplayer_1.1.0~rc4_amd64.deb
   ```
   安裝過程**不會**以 root 啟動作品、不會自動登入／登出／重開機、不會旋轉螢幕,也不會關閉系統安全措施。
4. 若機器上有舊的手動 r8／r9 安裝、同名桌面擴充套件或來路不明的設定,請**停止**並交由技術人員處理,
   不要直接覆蓋。

安裝完成後,應用程式選單裡會出現 **Transplayer 設定**、**開始 Transplayer**、**停止 Transplayer**。

## 第一次設定 / First setup（都在一般帳號的桌面操作）

1. 用展示帳號登入桌面,開啟系統「**設定 → 顯示器**」,把兩台螢幕設成各自正確的直向方向、
   延伸桌面、100% 縮放、左右相鄰頂端對齊,**套用並保留**。方向怎麼確認見下一節。
2. 從應用程式選單開啟 **Transplayer 設定**。
3. **選擇作品影片**(上一節放好的 `stonesandelephants.webm`)。
   若是要更換既有 r10 影片,勾選「確認變更既有 r10 影片設定」,舊設定會自動留私有備份。
   不要手動改 JSON 或借用別人的設定檔。
4. 自行決定是否勾選「**登入桌面後自動播放**」,再按「**儲存設定**」。
   注意:關掉視窗但沒按儲存,不會建立影片設定或自啟入口。
5. 按「**啟用桌面整合**」。若提示要重新登入,請先存好其他工作,**自行登出再登入**
   (工具不會替你登出)。第一次安裝系統擴充套件通常需要重新登入才會被 GNOME 載入。
6. 按「**檢查螢幕與桌面**」。沒通過就依提示修正,**不要**用隱藏頂部列／Dock 的方式硬繞過。
7. 按「**開始播放**」,親自確認:影片透明、滑鼠可穿透、聲音、圖片搜尋會跑、視窗會捲動。
   畫面顯示「已要求啟動」**不代表**視覺上已驗收成功——要用眼睛確認。

作品首次從 **775 秒**開始,之後回到 0 並依原時間軸循環;13 個搜尋事件、19 個時間點與視窗／捲動
編排都維持原作,不因安裝器而改動。

**展示瀏覽器使用未加密的專用密碼儲存——請勿在上面登入私人帳號或儲存密碼。**

## 螢幕方向與左右確認 / Display direction

每台螢幕依**實際吊掛方向**獨立選旋轉 **90°或 270°**:兩台同向或一正一反都行,
不旋轉影片,也不要靠接頭順序猜實體左右。

1. 先「停止播放」,再按「**開啟系統顯示器設定**」,在系統裡逐台選正確方向,
   排成左右相鄰、頂端對齊、延伸桌面、100% 縮放,確認並保留。
2. 回設定工具按「啟用桌面整合」並依提示重新登入後,按「檢查螢幕與桌面」。
3. 按「**顯示方向與左右測試圖(須先停止播放)**」。確認兩台的「↑ 上方／UP」都朝上、文字正向;
   「桌面左側／LEFT」在實體左邊、「桌面右側／RIGHT」在實體右邊。不對就退出測試圖、回系統修正,
   **不要**另做一份旋轉過的影片。
4. 按 Esc 或任一「關閉全部測試圖」即可全部關閉,120 秒後也會自動關。
5. 設定好後**重開機一次**,再確認系統確實保留了兩台各自的方向與位置。

## 日常操作 / Daily use

- **開始**:設定視窗的「開始播放」,或應用程式選單的「開始 Transplayer」。
- **停止**:用「停止播放」或「停止 Transplayer」,讓專用監管程序正常停止。
  **不要**只關閉影片視窗(監管程序會把它重新拉起來)。
- **開機自動播放**:勾選「登入桌面後自動播放」並儲存。
  這和「電腦開機自動登入」是兩件事——自動登入、休眠、鎖定、遠端存取由管理員依場地政策另外設定。
  若要開機自動播放,請管理員把展示帳號設成自動登入。

## 更新或移除 / Update or remove（重要:先停播再更新）

**不要在播放中直接更新套件**——套件會偵測到作品還在跑而拒絕維護。正確順序:

1. 在設定工具按「**停止播放**」,確認畫面與桌面已恢復。
2. 按「**準備更新或移除(須先停止播放)**」。成功後會結束本帳號的隔離監管程序並**暫時停用自啟**
   (資料保留)。
3. 由管理員核對新 `.deb` 的 SHA-256 後,用 `sudo apt install ./<新檔>.deb` 安裝,或移除套件。
   若系統回報「Player is active／維護被拒」,表示還有帳號在播——回到步驟 1 把它停掉。
4. 更新後重新開啟「Transplayer 設定」,確認影片與桌面、手動試播;需要自啟就重新勾選並儲存。
5. 更新完建議重開機一次,確認自動播放正常。

移除／purge 預設會**保留**外部影片、使用者設定、專用瀏覽器 profile、日誌與備份;
重新安裝可能還看得到原設定。要清私人資料請技術人員確認範圍另行處理。

## 效能 / Performance

作品影片是 **VP9 帶 alpha 透明通道**,內嵌 Chromium 對帶 alpha 的影片不走硬體解碼,
解碼落在 CPU。因此**播放順不順主要看 CPU**:

- 參考展場機(多核心 CPU＋RTX 4060)實測**掉影格 0**,播放順暢。
- 早期使用的雙核心 Celeron 機器會嚴重掉格(完整作品約 38%)——這類低階 CPU 不建議。

所以請用現代多核心 CPU 的機器;顯示卡負責畫面合成與透明,有獨立顯卡更穩。
相關一手證據見[效能分析](performance.md)。

## 常見問題 / Troubleshooting

- **找不到「桌面整合」或擴充套件沒生效**:確認桌面是 GNOME 50;依提示自行登出再登入;
  不要再手動裝一份同 UUID 的使用者擴充套件。
- **影片找不到／無法播放**:檢查影片是否還在原位置、外接碟是否掛載、展示帳號是否有讀取權限;
  回設定工具重新選片,不要刪備份或改擁有權。
- **出現 CAPTCHA／搜尋頁變成驗證畫面**:本版(rc4)已內建兩層自動處理——偵測到 Google 的
  `/sorry/` 驗證頁會自動重載一次,並載入 NopeCHA 自動解。偶爾出現通常會在幾秒內自行恢復,
  不需要人工。若持續卡住,交由技術人員查 `out.log` 的 `CAPTCHA sorry-retry` 記錄。
  不需要提供私人帳號或購買驗證額度。
- **搜尋結果空白**:可能是網路或網站限制;播放器啟動成功不代表每次搜尋都有結果。
- **Chrome 跳出「還原分頁／Restore session」**:本版已加設定抑制崩潰復原提示;
  若仍出現,交由技術人員核對版本與啟動參數,不要刪 profile 或鎖,也不要改用私人 Chrome 捷徑。
- **套件維護被拒／桌面狀態不符**:保留錯誤訊息交技術人員;不要刪 profile 鎖、維護標記,
  也不要用 PM2 resurrect。
- **要做基本診斷**:技術人員可執行 `transplayer doctor`,只輸出平台／桌面檢查與版本狀態,
  不是完整的播放／聲音／效能驗收。
