# User guide / 一般使用者指南

## Release status / 版本狀態

**目前是 Ubuntu 26.04 LTS amd64 自助安裝候選版 r10；尚未發布可下載安裝包，尚未完成實機驗收。**
以下步驟是候選版操作說明，待實際套件建置、授權審查與新機測試通過後才作為安裝流程。
不需要自行安裝 Git、Node、npm、Chrome、Driver 或 PM2；這些由正式發行包提供。
舊 Ubuntu 25.10 現場 r9 不使用本流程升級。

## Requirements / 準備項目

- 專用的 Ubuntu **26.04 LTS、amd64（x86_64）**電腦與一般展示帳號。
  目前只以預設 GNOME **50**、Ubuntu Dock、Wayland／Xwayland 為目標。
  ARM、其他桌面與其他 Ubuntu 版本未列為支援。
- 兩台各 **1080×1920** 的直向螢幕，左右相鄰、頂端對齊、縮放 **100%**，
  合成桌面 **2160×1920**；不使用鏡像顯示。至系統「設定 → 顯示器」調整。
- 取得作品原始影片：**2160×1920、約 780 秒**。影片不隨程式散布；
  放在展示帳號可讀取且持續掛載的本機位置，不要選會被拔除的隨身碟。
  設定工具不搬移、轉檔或覆寫影片。
- 安裝套件需要管理員授權；設定和播放則使用一般展示帳號，**不要 sudo**。
  即時圖片搜尋需要網路，第三方網站可能改版、離線或要求驗證，不能保證永不出現 CAPTCHA。
- 尚無 Ubuntu 26.04 實機效能數據或最低 CPU／GPU／RAM 保證。

## Install / 安裝

待專案實際發布 `.deb` 與 SHA-256 後，從專案確認的版本頁取得二者，
比對檔案雜湊與發行版本，再以系統可用的套件安裝介面開啟 `.deb`。
系統若沒有可用的圖形套件安裝器，請技術人員使用標準 apt 安裝。
目前不提供假下載連結，也不要求貼上遠端腳本。

技術備援命令（只適用已取得並驗證過的實際候選套件）：

```sh
sudo apt install ./transplayer_1.1.0~rc1_amd64.deb
```

安裝時不會以 root 啟動播放器，也不會自動登入、登出、重開機、旋轉螢幕或關閉系統安全措施。
遇到既有手動 r8／r9 安裝、同名桌面擴充套件或未知設定時，請停止並交由技術人員處理。

## First setup / 第一次設定

1. 登入展示帳號的桌面，從應用程式選單開啟 **Transplayer 設定**。
2. 選擇原作品影片。需要改換既有 r10 影片時，勾選「確認變更既有 r10 影片設定」；
   舊設定會保留私有備份。不要手動改 JSON 或借用他人的設定檔。
3. 自行決定是否勾選「登入桌面後自動播放」，再按「儲存設定」。
   關閉視窗且尚未按儲存，不會建立影片設定或自啟入口；
   工具可能已建立空的程式設定目錄及互斥鎖。
4. 按「啟用桌面整合」。若提示需重新登入，請儲存其他工作後自行登出再登入。
   工具不會代替你登出。初次安裝系統擴充套件也可能要重新登入才能被 GNOME 發現。
5. 按「檢查螢幕與桌面」。若未通過，依提示修正；不要永久隱藏頂部列／Dock 來繞過檢查。
   螢幕方向與左右位置的確認方式見下節。
6. 按「開始播放」，親自確認影片透明、滑鼠穿透、聲音、
   圖片搜尋與視窗捲動。顯示「已要求啟動」不代表視覺驗收成功。

作品首次由 **775 秒**開始，接著回到零並依原時間軸循環；
13 個搜尋事件、19 個時間點及視窗／捲動編排沒有因安裝器而改寫。

**展示瀏覽器使用未加密的專用密碼儲存；請勿登入私人帳號或儲存密碼。**
工具不修改系統鑰匙圈，也不向你索取登入密碼。

## Display direction / 螢幕方向與左右確認

每台螢幕依實際吊掛方式**獨立選擇旋轉 90° 或 270°**：
兩台同方向或一正一反都可以，不旋轉影片，也不以接頭順序猜測實體左右。
中央接縫對位不列為本次設定或驗收要求。

1. 先正常停止播放，再按「開啟系統顯示器設定」。
   在系統中逐台選擇正確方向，使用延伸桌面、100% 縮放，
   將兩台 1080×1920 螢幕排成左右相鄰、頂端對齊，確認並保留系統設定。
2. 啟用桌面整合並依提示重新登入後，按「檢查螢幕與桌面」。
3. 按「顯示方向與左右測試圖（須先停止播放）」。
   檢查兩台的「↑ 上方 / UP」都朝上、文字正向，
   「桌面左側 / LEFT」在實體左邊，「桌面右側 / RIGHT」在實體右邊。
   若不對，退出測試圖後回系統修正，不要另做一份旋轉影片。
4. 按 Esc 或任一「關閉全部測試圖」即可一起關閉；120 秒後也會自動關閉。
   螢幕配置變動或無法確認全螢幕位置時，工具會退出並提示重試。
5. 安裝人員安排重開後再確認一次，驗證系統確實保留兩台各自的方向與位置。

測試圖只是人工確認工具，不會自動判定實體安裝方向，也不會修改系統顯示設定。
這些操作及四種旋轉組合仍待 Ubuntu 26.04 新機實測。

## Daily use / 日常操作

- 開始：設定視窗中的「開始播放」，或應用程式選單的「開始 Transplayer」。
- 停止：使用「停止播放」或「停止 Transplayer」，由本程式專用 supervisor 正常停止。
  不要只關閉影片視窗或使用舊 AppRun 停止方式，以免監管程序重新啟動它。
- 自啟：勾選或取消「登入桌面後自動播放」，然後儲存。
  這不是「電腦自動登入」；自動登入、休眠、鎖定與遠端存取由管理員依場地政策設定。
- 登入時會有界重試桌面檢查，最多 30 次、兩次間隔 2 秒；
  若仍失敗就停止，不會為了通過而重開桌面或無限重啟。
  系統檢查本身另有逾時，因此此數字不是整個啟動流程的總秒數上限。

## Update or remove / 更新或移除

**不要在播放時直接更新。** 在每個使用過 r10 的展示帳號依序：

1. 按「停止播放」，確認畫面及桌面已恢復。
2. 按「準備更新或移除（須先停止播放）」。成功後會結束本帳號隔離監管程序，
   並停用本帳號自啟；不刪除資料。
3. 由管理員安裝已核對的新套件，或移除套件。若系統拒絕維護，停止並聯絡技術人員，
   不要強制移除或隨意終止其他程序。
4. 更新後重新開啟設定，確認影片及桌面，手動試播；
   需要自啟時重新勾選並儲存。不做背景自動升級。

移除／purge 預設保留外部影片、使用者設定、專用瀏覽器 profile、日誌及備份。
重新安裝時仍可能看到原設定。若要清除私人資料，請技術人員確認範圍後另行處理。
套件管理不是整個作品的自動回復系統；更新失敗需依[維運指南](operations.md)處理。

## Troubleshooting / 常見問題

- **找不到桌面整合**：確認使用 GNOME 50；依提示自行重新登入，
  不要安裝同 UUID 的使用者擴充套件副本。
- **影片找不到**：檢查外接磁碟是否掛載、影片是否移動，以及展示帳號是否有讀取權限。
  透過設定視窗重新選片，不要刪除備份或修改擁有權標記。
- **桌面／監管狀態不符、套件維護未完成**：保留錯誤訊息交由技術人員處理；
  不要刪 profile 鎖、套件維護標記或使用 PM2 resurrect。
- **搜尋變空白或出現驗證**：可能是網站／網路限制；播放器啟動成功不代表搜尋一定成功。
  不需要提供私人帳號或購買驗證額度。
- **Chrome 要求 Restore session／還原分頁**：r10 的展示瀏覽器啟動已加入隱藏崩潰復原提示的設定，
  包含異常後重建；實際無提示仍待新機測試。若仍出現，交由技術人員核對發行版本與啟動參數，
  不要刪除 profile 或鎖，也不要以私人 Chrome 捷徑代替展示入口。
- **需要診斷**：技術人員可執行 `transplayer doctor`，
  只輸出平台／桌面檢查與候選版狀態；不是完整播放、聲音或效能驗收。
